# 简盒 v3.9.7 更新与强制锁修复说明

## 版本信息

- applicationId：`com.jianbox.app`
- versionCode：`21`
- versionName：`3.9.7`
- 构建类型：Debug

## 本次修复

1. 更新查询同时读取 `stable` 和 `beta` 渠道，测试版使用独立蓝色标识。
2. 接入 `app_announcements`，支持普通、成功、提醒和重要公告，以及目标版本范围。
3. 公告按数据库 ID 在本机记录已读，同一公告每台设备显示一次。
4. 强制更新状态写入本机持久锁；应用恢复前台、重启应用或重启手机后仍会拦截。
5. 触发强制更新时立即停止悬浮球服务，并阻止悬浮浏览器、完整个性化设置和其他 Activity 入口。
6. 修复跨 Activity 弹窗复用漏洞：新页面会接管强制更新弹窗，不会因旧页面已有弹窗而变成可操作状态。
7. 主界面在渲染任何控件前先检查强制更新锁，首次启动页也会检查已缓存的锁。

- `app_announcements` 只允许读取已发布且处于生效时间范围内的记录。

- `assembleDebug`：成功。
- APK Signature Scheme v2：验证通过。

## 测试方法

当前线上已发布的稳定版也是 `versionCode 21`，所以本 APK 不会提示更新到自己。测试更新时请在后台新建更高版本：

- 普通测试版：`versionCode 22`、渠道“测试版”、最低可用版本 `1`、关闭强制更新，上传 APK 后发布。
- 强制更新：`versionCode 22`、最低可用版本 `22`、开启强制更新，上传 APK 后发布。
- 公告：新建并发布一条公告。若重复测试同一个公告 ID，需要清除应用数据或新建另一条公告。

发布后重新进入前台，或在“我的 > 版本服务 > 检查更新”中手动检查。强制更新测试期间，悬浮球服务会停止，悬浮浏览器和完整个性化入口不能绕过阻断。
